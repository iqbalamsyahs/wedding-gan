# Animations 1–6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menyelesaikan enam animasi untuk undangan: (1) pembukaan sampul, (2) ornamen yang terbuka dari kiri ke kanan, (3) reveal bertahap, (4) parallax dan dekorasi melayang, (5) countdown dengan efek flip, (6) ucapan baru yang masuk dengan animasi.

**Architecture:** Semua animasi dikerjakan dengan CSS dan React state yang sudah ada. `Reveal.tsx` (IntersectionObserver) menjadi pemicu untuk reveal dan ornamen. Parallax memakai satu listener scroll yang menulis `transform` langsung ke DOM, tanpa re-render React. Tidak ada library animasi baru.

**Tech Stack:** Next.js 16 (App Router), React 19, Tailwind CSS 4, TypeScript.

**Spec:** Tidak ada file spec. Persyaratan ada di Goal di atas, dari permintaan 2026-10-11. `docs/PRD.md` tidak mencakup animasi.

**Status awal:** Nomor 1 dan 2 sudah diimplementasikan di working tree (belum di-commit). Plan ini memverifikasinya di Task 1, tidak menulis ulang.

## Global Constraints

- Tidak menambah dependency. Animasi memakai CSS, React state, dan satu listener scroll.
- Tidak mengubah file aset di `public/assets`.
- Semua animasi dimatikan atau disederhanakan di `prefers-reduced-motion: reduce`.
- Bahasa antarmuka tetap Indonesia.
- Tidak melakukan commit kecuali diminta.

## Review Focus

1. Dengan reduced motion, semua konten langsung tampil utuh tanpa transisi, termasuk ucapan dan countdown.
2. Parallax tidak membuat foto sampul terpotong atau menampilkan area kosong di bawahnya saat scroll.
3. Countdown tidak bergeser lebar saat angka berubah. Ditangani dengan `tabular-nums`.
4. Listener scroll dibersihkan saat komponen unmount, tanpa kebocoran.
5. Ucapan baru tetap bisa dibaca saat animasinya berjalan, dan tidak berpindah posisi secara tiba-tiba.

- [ ] **Step 1: Tambahkan prop `delay` ke `Reveal`**

Ganti seluruh isi `components/atoms/Reveal.tsx` dengan:

```tsx
"use client";

import { useEffect, useRef, useState } from "react";

export default function Reveal({
  children,
  className = "",
  delay = 0,
}: {
  children: React.ReactNode;
  className?: string;
  delay?: number;
}) {
  const ref = useRef<HTMLDivElement>(null);
  const [visible, setVisible] = useState(false);

  useEffect(() => {
    const el = ref.current;
    if (!el) return;

    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setVisible(true);
          observer.disconnect();
        }
      },
      { threshold: 0.15 },
    );

    observer.observe(el);
    return () => observer.disconnect();
  }, []);

  return (
    <div
      ref={ref}
      className={`reveal ${visible ? "is-visible" : ""} ${className}`}
      style={{ transitionDelay: `${delay}ms` }}
    >
      {children}
    </div>
  );
}
```

1. Tambahkan `useRef` untuk wrapper foto. Wrapper `.cover-photo` mendapat `ref={photoRef}`.
2. Tambahkan `useEffect` untuk listener scroll:

```tsx
  const photoRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) return;

    const onScroll = () => {
      if (photoRef.current) {
        photoRef.current.style.transform = `translateY(${window.scrollY * 0.2}px)`;
      }
    };

    window.addEventListener("scroll", onScroll, { passive: true });
    return () => window.removeEventListener("scroll", onScroll);
  }, []);
```
